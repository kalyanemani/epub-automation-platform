EPUB Autofix — LLM Call Analysis

How many calls are made per job, which models handle them, and how the 3-tier fallback works

Pipeline Steps & LLM calls per step

0
EPUB Content Indexing (background) 0 LLM calls
Fires EPUBContentIndexer as a non-blocking background task. Embeds up to 10 CSS + 20 HTML files into epub_{run_id} ChromaDB collection using BGE-M3. Pure embedding — no LLM involved.
↓
1
Triage 0 LLM calls Deterministic
Pure Python rule-based routing — no LLM. Each issue ID is looked up in AUTO_FIX_RULES, LLM_FIX_RULES, or MANUAL_REVIEW_RULES sets. Issues are tagged with routing (auto / llm / hitl) and task_type (codegen / structured / reasoning / vision) in milliseconds. use_llm_triage is always False in the autofix pipeline.
↓
2
Node.js AUTO Fixes 0 LLM calls Deterministic
Node.js /autofix endpoint handles structural/metadata rules (mimetype, NCX, OPF fields, etc.) with hard-coded transformations. Returns a patched EPUB binary. No LLM involved.
↓
3
KB Lookup (per LLM-routed issue) 0 LLM calls BGE-M3 Embedding
For each unique rule routed to LLM, _get_kb_context() embeds the issue query with BGE-M3 (768-dim), runs hybrid search (65% dense cosine + 35% BM25), and returns the top KB passages as context_text. This is embedding inference, not an LLM generation call.
↓
4
Domain Agent Fixes — the only LLM calls 1 call per unique LLM-routed rule
Four agents run concurrently via asyncio.gather. Each agent calls ollama_generate() once per unique issue rule it handles. Issues with the same rule ID (e.g., 5 files all missing L_CSS_CLASS_SELECTOR_MISSING) share one LLM call — the patch is applied to all instances.

Cache hit (memory.get_cached_prompt) → skips the LLM call entirely, model_used = "cache".
↓
5
HITL Suggestions (parallel with Step 4) 1 call per unique HITL rule
HITL issues go through the same domain agents (same asyncio.gather call as Step 4) to generate advisory suggestions. Same model, same concurrency. These fixes are never applied automatically — output is shown to human reviewers.
↓
6
EPUBPatcher + Trace Build 0 LLM calls
Writes LLM-generated patches into the EPUB file using deterministic XML/CSS manipulation. Builds the fix_trace list. The ValidatorAgent exists in code but is not called from the autofix pipeline — it's an available endpoint only.

Concurrency Model

All domain agent tasks fire in one asyncio.gather() — they're truly concurrent, not serial. Semaphores prevent thundering herd at the model server.
