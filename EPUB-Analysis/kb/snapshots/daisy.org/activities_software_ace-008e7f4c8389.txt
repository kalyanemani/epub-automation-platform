It has been developed to assist in the evaluation of conformance to the EPUB Accessibility Specification. Who is this for? Ace by DAISY is for anyone who is using EPUB to create accessible content for publication. It can be used at any point in a book production workflow and is therefore suitable for use by the many and varied departments and third party vendors involved in the publishing industry. Ace by DAISY can also be used by self publishing authors and anyone else wanted to test the accessibility of an EPUB file which does not have digital rights management Status Release Status The command line tool for Ace by DAISY was first released in January 2018 the Ace App graphical user interface version was released in the summer of 2019. Both versions regularly receive updates. Development site For technical detail on the ongoing development work for Ace by DAISY, visit the github site .
