# Sprint 1 Backlog Summary

Source: feedback provided in the Product Improvement Action Plan dated April 10, 2026.

## Sprint Goal

Make the EPUB validation and auto-fix product more production-ready by improving navigation, reducing review noise, adding exportable reports, introducing run traceability, clarifying the preferred input path, and tightening release-readiness controls.

## Backlog Shape

- Total backlog items: 10
- Committed items: 8
- Stretch items: 2
- Total estimated effort: 49 story points
- Committed effort: 38 story points
- Stretch effort: 11 story points

## Committed Items

- SP1-01: Icon-based step navigation with progress state
- SP1-02: Default issue filter to Fail and Warn plus Show Passed toggle
- SP1-03: Downloadable Pre-Validation report export
- SP1-04: Downloadable Post-Validation report export
- SP1-05: Comparison report with rule-level delta and unresolved items
- SP1-06: Run IDs and immutable artifact snapshots
- SP1-07: EPUB-first default workflow
- SP1-09: Embedded JavaScript policy detection and severity reporting

## Stretch Items

- SP1-08: Asynchronous PDF conversion queue with progress tracking
- SP1-10: Landing page upload guidance and CTA cleanup

## Items Intentionally Left For Later Sprints

- Glossary-driven relabeling and business-friendly terminology refresh
- Issue cards grouped by category and confidence
- Standardized report schema with release-stable metadata and flags
- File-level and snippet-level attribution for Rule, RAG, LLM, and Manual changes
- Rollback and re-run from prior snapshots
- Dual-input EPUB plus PDF reference mode
- Debug panels for Rule, RAG, and LLM observability
- Release gate checklist for functional, regression, reporting, and security sign-off
- Synthetic data injection packs and internal test mode flow
