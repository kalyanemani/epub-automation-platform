0EPUB Content Indexing background
Runs non-blocking, in parallel with all other steps:
  • Unzips EPUB to temp dir
  • Reads ≤10 CSS files + ≤20 HTML files (≤60KB each) + OPF
  • SmartChunker: CSS→css_rule, HTML→hierarchical, else→semantic
  • ChromaIndexer deduplicates by MD5 of content[:200]
  • Stores in collection epub_{run_id}

11KB lookup — per issue, all parallel
For each LLM-routed unique rule (asyncio.gather):
  • Embed query: BGE-M3 + instruction prefix
  • Hybrid search across collections:
    epub_{run_id}, kb_css, kb_js, epub_rules, issue_patterns
  • 65% dense cosine + 35% BM25 Okapi, threshold 0.35
  • Top 6 chunks → context_text (≤2000 chars)
  • Cache result 30 min in Redis
